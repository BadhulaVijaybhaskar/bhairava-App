# AI UI Toolbox

A directory of AI tooling for interface work. Use it to answer "what should I
use for X" — do not install anything without the user asking.

Full list: `knowledge://skill/ai-ui-toolbox/references/tool-directory.md`
(sections: Skills, Apps, MCP Servers & Plugins, Design Tools, Resources).

## Quick picks

| Need | Suggest |
|---|---|
| Design-system generation inside the agent | UI UX Pro Max skill, Impeccable |
| Stop generic AI-looking output | Taste Skill, Anthropic frontend-design skill |
| Component code that matches an existing setup | shadcn/ui skills |
| Automated design review of a diff | Vercel web-design-guidelines, Claude Code design-review workflow |
| Micro-interaction polish | Emil Kowalski skill, Make Interfaces Feel Better |
| Swiss/editorial typographic direction | Swiss Design System |
| 3D / WebGL | Three.js skills |

## Rule

Recommendations are advisory. When work happens inside this project, apply the
project's own design system and active skills first; reach for an external tool
only when the user explicitly wants it.
